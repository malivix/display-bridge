# Task-oriented usage guide

Reorganized the accumulated usage notes into a control map and focused sections for
readability/keyboard navigation, snapshots, size presets, brightness, compatibility,
speakers/recovery, reports/privacy, troubleshooting and Terminal commands. Preserved
preview deadlines, orientation scope, revision semantics, recovery limits and qualification
caveats. The README links directly to everyday tasks and explains that updating source
does not update the installed application. The documentation index now links the current
milestone and comparison instead of older review documents.

CLI examples consistently use the installed launcher, whose implementation was checked
to preserve the installation's selected Python. Verified 27 local links and anchors plus
balanced code fences; reviewed commands against their parser/handlers. Documentation-only
change: no hardware commands or runtime tests were run, and no installed files changed.
