# Prioritize actionable setup findings

Show error/warning counts and the first error's action (otherwise first warning) before
the full setup checklist. Preserve report order within each severity and all detailed
findings. Informational-only reports explicitly do not establish physical qualification.
Do not invent installer commands or automatically execute suggested actions.

Decode the read-only health contract once for Health and Setup: nonempty bounded checks,
known statuses, required names/details, true JSON read-only flag and consistent aggregate
status. Invalid data becomes unavailable, not ready. Missing enrollment checks remain
explicitly unreported. No controller or persisted schema change; rollback is a menu rebuild.
Validate error priority, invalid reports, informational-only and absent-action fallback;
inspect the synthetic setup result at Largest without contacting hardware.
